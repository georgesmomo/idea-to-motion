# Genres: structures, budgets, hooks, end cards

Universal spine: `HOOK → STAKES → BODY (1–4 beats) → TURN → PAYOFF → END CARD`.
The hook is on screen at frame 0 (no logo intro, no fade from black). The payoff answers the
hook. A new visual stimulus every 1.5–3 s. Scenes: 3–4 at 15 s, 5–6 at 30 s, 8–10 at 60 s.
A scene under 2 s is a cut inside a scene; over 10 s needs a camera move or a focus change.

Budgets are seconds for 15 / 30 / 60 s versions; interpolate for other lengths, and snap to
music bars (`motion beats`).

| Genre | Typical | Beats (15 / 30 / 60) | Hook | Signature moves (kit) | End card |
|---|---|---|---|---|---|
| **Product launch / teaser** | 15–30 | tease 0–2 / reveal 2–9 / 2 benefits 9–13 / CTA 13–15 · ×2 for 30 | "Something is coming", a silhouette or a mask | `reveal mask`, `shine`, `zoom`, `panel` wipe, `boom` on reveal | name + date + URL |
| **App feature demo** | 20–45 | pain 0–3 / feature ×3 (5 s each) / CTA | the pain in ≤ 5 words | `.mo-phone` / `.mo-browser` mockups, `zoom` into the UI, `type` in a field, `ok` | store badge / URL + "Try it" button |
| **Explainer** | 45–90 | hook 0–5 / problem 5–15 / idea 15–30 / how (3 × 8) 30–54 / proof 54–60 / CTA | a question or a surprising fact | `diagram`, `draw` icons, `along` paths, camera pans, `focus` | one-line takeaway + CTA |
| **Social ad** | 9–20 | hook 0–2 / benefit 2–8 / proof 8–11 / CTA 11–15 | a bold claim, huge | fast cuts, `punch`, `stamp` price, `count` | CTA button visible from 70 % |
| **Event promo** | 15–30 | title 0–3 / lineup or program 3–9 / date + place 9–13 / CTA 13–15 | the date as giant numerals | beat-synced `punch`, `count` down, marquee rows | date + place + tickets URL |
| **Educational / history / science** | 45–120 | question 0–5 / 3–5 steps / recap / next | "Why…?" / "Did you know…?" | `timeline`, `draw` maps/diagrams, labels, `scribble circle` | the one takeaway |
| **Kinetic quote** | 10–30 | word per beat build, hold 2 s, author 1.5 s | the first word at frame 0 | `punch`, `lines`, `mark`, size and weight contrasts | author + handle |
| **Data story** | 30–60 | context 0–4 / big number 4–10 / chart 10–22 / insight 22–27 / source | the surprising number, counted up | `count`, `bars`, `lineChart`, `ring`, `focus` on the key bar | source line + takeaway |
| **Logo reveal / sting** | 4–8 | build 0–2.5 / hit 2.5–3.5 / settle + tagline | an abstract shape resolving | `draw` the logo strokes, `morph`, `shine`, `burst`, `boom` | logo + tagline ≥ 1.5 s |
| **Listicle / top N** | 20–60 | hook 0–2 / N items (4–5 s each) / outro | "N things you…" | numeral wipes (`.mo-num`), one card template reused, `panel` between items | "Follow for more" / CTA |
| **Celebration** (birthday, wedding, congrats) | 10–20 | name 0–3 / message 3–9 / peak 9–12 / sender | the name, huge | `chars`, `confetti`, `burst`, `float` balloons, pop | sender's name |
| **Recipe / how-to** | 30–60 | dish 0–3 / ingredients 3–9 / steps (5 s each) / result | the finished dish named | emoji icons grid, step numbers, `ring` timers | recipe name + "save it" |
| **Real estate / place** | 30–45 | place + price 0–4 / 3 specs (5 s each) / features / contact | address + price | floor plan `draw`, `count` m², map pin `along` | agent + phone / URL |
| **NGO / cause** | 45–90 | a person or a number 0–10 / scale 10–20 / solution / impact / ask | one human detail or one number | slow `lines`, `count`, `scribble underline`, Open Peeps people | donate / sign URL |
| **Personal brand / portfolio** | 20–45 | name + role 0–3 / 3 proofs / contact | "I help X do Y" | `chars`, `mark`, logos row, `count` results | handle + URL |
| **Tech explainer** (repo, architecture, pipeline) | 30–60 | see the dedicated skill `tech-to-motion`, or: hook / map build / packet run / dive / twist / takeaway | a counter-intuitive claim | `diagram` + `flow`, `type` in `.mo-term`, `fail` / `ok` | takeaway + repo URL |

## Hook patterns (any topic)

| Pattern | Example |
|---|---|
| Counter-intuitive claim | "Your brain deletes 70 % of what you learn today." (fact-checked) |
| Concrete number | "12 → 58 orders a day." |
| Question with a visual | "What does a croissant have to do with the sun?" + the morph |
| Before / after | "6 a.m. chaos → 90-second coffee" |
| Direct address | "You, yes you, scrolling at 1 a.m." |
| "Stop doing X" | "Stop writing to-do lists." |
| Countdown | "3 days." huge, ticking |
| Name, huge | "LÉA" for a birthday |

Hook rules: ≤ 8 words, readable at frame 0, motion already happening at frame 0, the number or
claim in facts.md.

## Picking the one idea

Ask: what will the viewer repeat to a friend? Good: "the 90-second brew saves you 20 minutes
a day". Bad: "here are our 7 features". If the brief has a surprising fact, a tension or a
transformation, that is the story; everything else is setting.

## Durations by platform

| Where | Ratio | Length that performs | Notes |
|---|---|---|---|
| TikTok / Reels / Shorts | 9:16 | 15–35 s | hook in 1 s; universal safe area; loop the end to the start when possible |
| Instagram / LinkedIn feed | 1:1 or 4:5 | 15–30 s | mostly muted: every idea on screen |
| X | 16:9 or 1:1 | 15–45 s | muted autoplay |
| YouTube / website hero | 16:9 | 30–90 s | sound on more often; voice-over helps |
| Presentation / event screen | 16:9 | 10–60 s | no CTA URL needed; slower holds |
| Story / status | 9:16 | 5–15 s | one message |
